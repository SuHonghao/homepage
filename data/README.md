# 主页内容维护

本次简历修订的数据保存在 `cv-content.json`。运行 `python update_cards.py` 会同步主页及独立模块页。

- JSON 中的模块优先于历史 Excel；没有 JSON 数据的 `honors` 模块继续读取原 Excel，保留原校级荣誉。
- 基础资料来源：用户提供的《苏鸿皓-CV.pdf》（2026.10 版本）。
- 实习起始日期按用户 2026-10-28 的页面批注采用 2026.02；PDF 中为 2026.03。
- 论文作者身份、接收和投稿状态按简历保留，不把预印本或在投写成正式接收。
- 每条记录支持 title、time、descriptions、images、role、links；images 使用相对项目根目录的图片路径。
- 缺失图片时正常显示文字，不输出破图或虚构图片。
- “三生渡”项目图片使用用户提供的原图；Bench2Arena 主图提取自用户提供的论文 PDF 第 2 页 Figure 1。
- RoboDojo 按用户要求标注“核心工作”，不展开个人贡献。

顺序：教育经历、实习经历、主要论文、项目经验、竞赛获奖、校级荣誉、学生工作、社会实践、其他经历。
